HYBRID-X1Final project

One board. Two smart products.

HYBRID-X1 joins an Arduino Uno, an ESP32 and a Raspberry Pi 4 on one board. It runs a smart irrigation system for farms and a smart home controller, each with a web dashboard and a mobile app.

Arduino: senses and switches

Reads soil, tank, gas, smoke, water and motion sensors, and switches pumps, valves, lights, fans and the door lock.

ESP32: connects

Rain, flow, humidity and Bluetooth presence readings, sent over WiFi and MQTT. It can also be updated over WiFi.

Raspberry Pi: thinks

Applies the rules, keeps the history database, runs the AI, sends Telegram alerts and serves the app.

The two products

🌱 Smart Irrigation

Three crop zones, weather forecast, evapotranspiration watering, flow meter, plant disease AI, fault detection and a solar-powered option.

🏠 Smart Home

Scenes, voice commands, face recognition at the door, Bluetooth presence, energy anomaly detection, learned routines and safety sensors.

The dashboards and apps in this page are simulations that run in your browser. The hardware code is written and syntax-checked but has not been tested on real boards.

Build guide

What you need and how to run it for real.

1. Parts

Both projects

HYBRID-X1 board (or Arduino Uno + ESP32 DevKit + Raspberry Pi 4), 12 V supply, relay modules, jumper wires, microSD card (16 GB or more).

🌱 Irrigation

3 capacitive soil sensors, water level sensor, LM35 temperature sensor, rain sensor, DHT22, YF-S201 flow meter, 3 solenoid valves, Pi camera. Optional: solar panel and battery, pH/EC/NPK sensors, LoRa module.

🏠 Smart Home

3 PIR motion sensors, MQ-2 gas sensor, smoke and water-leak sensors, door lock solenoid and reed switch, doorbell, motorised water valve, gas valve, camera, USB microphone.

2. Setup on the Raspberry Pi

StepInstall the tools: sudo apt install mosquitto python3-pip python3-flask python3-serial caddy and pip3 install paho-mqtt requests
Secure MQTTCreate a user with mosquitto_passwd and turn off anonymous access.
Upload firmwareArduino: the sketch for your project. ESP32: set WiFi name, password and Pi IP, then upload once by cable. After that it updates over WiFi.
Start the hubexport HUB_TOKEN=your-secret then run pi_irrigation_mqtt.py or pi_home_mqtt.py
Open the appOn your phone open http://<pi-ip>:5000, enter the token, then Add to Home Screen. Do not use 1234, because that opens the demo.
Telegram (optional)Create a bot with @BotFather, then set TG_TOKEN and TG_CHAT.
AI (optional)Add a plant disease model for disease_detect.py, family photos for face_door.py, and a Vosk model for voice.py.

4. Safety

Switching mains-voltage lights and fans must be done by a qualified electrician. Real gas, smoke and water alarms must use certified detectors. HYBRID-X1 adds alerts and automatic actions on top of them, never in place of them. Test every part on its own before relying on it, and do not expose the Pi directly to the internet: use HTTPS and a VPN such as Tailscale.
